# Leslie / Play brand mark

The mark is a small pinwheel made from four rounded game tiles. It represents
separate pieces gathering into a playable system: fitting, lighting, sorting,
and discovering.

## Use

- Use `assets/leslie-play-mark.svg` beside the Leslie / Play wordmark.
- Use `assets/favicon.svg` for browser tabs and small square avatars.
- Keep at least one quarter of the mark's width as clear space.
- Never stretch, recolor individual tiles, add shadows, or place text inside it.
- At very small sizes, use the mark alone. At normal sizes, pair it with
  `LESLIE / PLAY`.

## Design principle

The identity should feel like an identifiable maker's signature, not a game
publisher's corporate badge. Its playful irregularity is intentional, while the
simple geometry keeps it reusable across future games and social images.
